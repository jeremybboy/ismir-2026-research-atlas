# Five-region taxonomy audit

## Conjecture

For this accepted-paper dataset, one of five title-derived regions can serve as each paper's primary map location without implying exclusivity, provided independent concept tags preserve hybrid meaning.

## Falsifier

This conjecture fails as a complete classification if a paper legitimately spans regions, if evaluation or culture is orthogonal to its subject, or if title resemblance is treated as proof of methodological similarity.

## Attempt to break it

| Test case | Counterexample | Diagnosis |
|---|---|---|
| *Separate-and-Detect* | Transcription, stem generation, diffusion, and production all apply. | Hybrid; one primary region is only a layout choice. |
| *Does Notation Matter?* | Generation and understanding share one title. | Primary-region exclusivity fails. |
| AI-generated-stem detection papers | Evaluation acts on production/generation outputs. | Evaluation is often orthogonal. |
| Ethiopian Kiñit, Arabic Maqam, and Pansori papers | Cultural scope coexists with analysis, representation, or transcription. | Culture is not an exclusive subject family. |
| Papers sharing “diffusion” | A model family can support unrelated tasks. | Shared wording does not prove intellectual or methodological similarity. |

## Verdict

**SURVIVES WITH TAGS — ENCODING failure, high confidence for the communication model.** The five regions remain useful navigation fields, but they fail as exclusive scientific categories.

## Smallest defensible revision

Keep one primary region only for deterministic layout; encode overlap through multiple title-level concept tags and state shared tags on related-paper links. Describe counts only as title-derived cluster sizes, never research activity or importance.

## Remaining hard case

A vague or metaphorical title may not expose enough evidence for a defensible primary region or concept tags; future proceedings metadata could require explicit reclassification.

## Communication calibration

This is a **qualified simplification** for research discovery. The minimum qualifier is: “Topics, positions, connections, and trails are exploratory interpretations inferred from titles and metadata.”
