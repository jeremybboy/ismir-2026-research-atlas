# Contributing

Thank you for improving the ISMIR 2026 Research Atlas.

## Corrections

Use the data-correction issue template for title, author, affiliation, or source-link problems. Cite the official ISMIR page or another primary source and distinguish exact metadata corrections from proposed editorial classifications.

## Classification changes

Topic regions, concept tags, related-paper links, and trails are title-and-metadata interpretations. A proposal should name the affected paper, state the title-level evidence, identify hybrid or ambiguous cases, and explain why the change improves exploration without implying official endorsement.

## Development

1. Create a focused branch from `main`.
2. Make the smallest coherent change.
3. Run the documented validation suite.
4. Stage explicit paths only and open a pull request.
5. Do not merge your own agent-generated pull request.

By participating, you agree to follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
