# Security policy

## Reporting

Do not open a public issue for a vulnerability that could expose users or maintainers. Use GitHub's private vulnerability reporting if available, or contact the repository owner through the profile listed on the repository.

## Supported version

Until the first tagged release, only the current default branch is supported. This is a static, client-side application: reports should focus on dependency, workflow, supply-chain, or browser-security problems rather than server-side concerns that do not exist here.
